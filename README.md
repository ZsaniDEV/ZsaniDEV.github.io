# Helló, világ! — kezdő weboldal

Egyszerű, reszponzív statikus weboldal HTML, CSS és JavaScript használatával.

## Futtatás helyben

Nyisd meg az `index.html` fájlt egy böngészőben. Nincs szükség csomagtelepítésre vagy buildlépésre.

## Fájlok

- `index.html` — oldal tartalma
- `styles.css` — megjelenés és reszponzív elrendezés
- `script.js` — a gomb interakciója

## Telepítés

A `.github/workflows/pages.yml` GitHub Actions munkafolyamat a `main` ágra történő push után telepíti az oldalt GitHub Pagesre. A Pages szolgáltatást a repository beállításaiban GitHub Actions forrásra kell állítani.
